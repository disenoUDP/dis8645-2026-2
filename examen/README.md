## proyectos previos

antes de este examen hicimos 3 proyectos.

- proyecto-uno: un proyecto autocontenido, usando las placas Arduino Uno R4.
- proyecto-dos: pie forzado de usar dos perillas y dos botones, escribir sus propias clases, compartirlas con otro equipo, usando la placa Raspberry Pi Pico 2W.
- proyecto-tres: ejercicio de descripción textual, diagramática de un proyecto complejo, con pie forzado de usar 1 parlante. este proyecto luego se implementa y se presenta como examen.

## organización de los archivos

cada grupo trabaja dentro de su carpeta, donde existen las subcarpetas:

- animaciones/: con animaciones en formatos gif
- audios/: con audios en formato .wav, .mp3 o similar.
- codigos/: con los códigos de los dispositivos creados, en archivos .h, .cpp y similar.
- imagenes/: con imágenes en formato .png, .jpg o similar.
- pdfs/: con documentos en formato .pdf, como diagramas, descripciones, etc.

## organización del archivo principal README.md

debe incluir las siguientes secciones:

- integrantes y roles
- descripción conceptual del proyecto
- descripción técnica del proyecto
- descripción del proceso de desarrollo
- diagramas de flujo
- lista de materiales
  - incluir lo conseguido prestado o de laboratorio de interacción digital
  - incluir lo comprado, boletas
- horas de trabajo
- declaración de uso de ia: dónde y cómo la usaron, incluir conversaciones, mostrar prompts, resultados
- 3 aprendizajes importantes y cómo se aplican a su vida post taller
- 3 dificultades encontradas, y cómo se resolvieron
- referentes con análisis
- bibliografía en apa
